# ⚔ Duelo das Almas

Jogo de cartas online para Windows.

## ⬇ [BAIXAR O JOGO (Windows)](https://github.com/Jokerzk1/DUELOALMAS/releases/latest)

1. Clique no link acima e baixe o arquivo **Instalar-Duelo-das-Almas.exe**.
2. Abra o instalador e siga os passos. Ele cria o atalho **Duelo das Almas** na área de trabalho.
3. Abra o jogo, crie sua conta e jogue.

> Se o Windows mostrar **"O Windows protegeu o computador"**, clique em **Mais informações → Executar assim mesmo**.
> Isso acontece porque o jogo ainda não tem assinatura digital paga.

### Atualizações
O jogo **se atualiza sozinho** toda vez que você abre. Não precisa baixar de novo.

---
<sub>`servidor.json` guarda o endereço atual do servidor; o jogo lê esse arquivo sozinho. Não mexa nele.</sub>
